# AI Text Recognizer

Проект реализует распознаватель текстов, предназначенный для определения происхождения текста: написан ли он человеком или сгенерирован моделью искусственного интеллекта.

Распознаватель ориентирован на исследовательскую задачу обнаружения AI-generated текстов, в том числе в области информационной безопасности. В проекте используются текстовые датасеты на русском и английском языках, извлечение признаков, машинное обучение и оценка качества классификации.

---

## Возможности

* Подготовка и объединение датасетов в формате JSONL.
* Работа с русскоязычными и англоязычными текстами.
* Извлечение признаков из текстов.
* Обучение классификатора для распознавания AI-generated и human-written текстов.
* Сохранение обученных моделей в формате `.pkl`.
* Использование кэша признаков для ускорения повторных экспериментов.
* Оценка качества модели с помощью метрик классификации.
* Проверка распознавания на пользовательских текстах из папки `input`.

## Формат данных

Данные хранятся в формате JSONL, где каждая строка представляет собой отдельный JSON-объект с текстом и меткой класса.

Ожидаемая логика разметки:

| Класс   | Значение                      |
| ------- | ----------------------------- |
| `human` | текст написан человеком       |
| `ai`    | текст сгенерирован моделью ИИ |

Точный набор полей зависит от конкретного датасета и обрабатывается в файлах `dataset.py` и `collect_dataset.py`.

## Обучение классификатора

Для обучения модели используется файл:

```text
classifier.py
```

В качестве базового классификатора может использоваться логистическая регрессия с L2-регуляризацией. Такой подход подходит для исследовательской задачи, поскольку он:

* хорошо работает на признаковом описании текстов;
* быстро обучается;
* позволяет подбирать силу регуляризации;
* является интерпретируемым по сравнению с более сложными моделями;
* удобен для сравнения разных наборов признаков.

Обученные модели сохраняются в формате `.pkl`.

Примеры сохранённых моделей:

```text
detector_en.pkl
detector_ru_sec.pkl
```

## Оценка качества

Оценка качества выполняется с помощью скрипта:

```powershell
python evaluate.py
```

Для анализа качества классификации могут использоваться следующие метрики:

| Метрика   | Смысл                                                                    |
| --------- | ------------------------------------------------------------------------ |
| Accuracy  | доля правильно классифицированных текстов                                |
| Precision | доля действительно AI-текстов среди текстов, которые модель отнесла к AI |
| Recall    | доля найденных AI-текстов среди всех настоящих AI-текстов                |
| F1-score  | гармоническое среднее между Precision и Recall                           |

Для задачи распознавания AI-generated текстов особенно важны Precision и Recall, поскольку модель должна не только находить сгенерированные тексты, но и не относить слишком много человеческих текстов к AI.

## Ограничения

* Качество распознавания зависит от состава обучающего датасета.
* Модель может ошибаться на коротких, шаблонных или сильно отредактированных текстах.
* Тексты, сгенерированные современными LLM и затем вручную изменённые человеком, могут быть сложнее для обнаружения.
* Результаты для русского и английского языков могут отличаться из-за различий в объёме и качестве данных.
* Распознаватель не должен использоваться как единственное основание для принятия критически важных решений.
